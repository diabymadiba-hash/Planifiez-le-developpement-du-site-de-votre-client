# Menu Maker by Qwenta — Gestion de Projet

> Projet réalisé dans le cadre de la formation **Développeur Front-end** chez OpenClassrooms.

---

## 📋 Contexte du projet

**Client :** Qwenta — leader de l'impression de supports pour les professionnels.

**Objectif :** Développer un outil en ligne permettant aux restaurateurs de créer, personnaliser et diffuser leurs menus facilement, en quelques clics.

**Rôle :** En tant que développeur front-end chez Webgencia, j'ai été chargé de préparer et planifier le projet en l'absence du Product Owner.

## 🛠️ Stack technique retenue

| Besoin | Solution |
|---|---|
| Framework front-end | React |
| Navigation | React Router DOM |
| Formulaires | React Hook Form |
| Modales | react-modal |
| Polices | Google Fonts API |
| Couleurs dynamiques | react-colorful |
| Upload logo | FileReader (natif) |
| Export PDF | jsPDF + html2canvas |
| Back-end | Node.js + Express.js |
| Base de données | PostgreSQL |
| Hébergement front | Vercel |
| Hébergement back | Railway |
